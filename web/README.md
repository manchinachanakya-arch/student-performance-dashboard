# Forma — Premium Student Insights Website

A React + Vite frontend for the Student Performance Analytics project. It is intentionally kept in the `web/` folder so the original Streamlit/Python application remains unchanged.

## Run locally

From this folder:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Features

- Premium classic ivory, charcoal and muted champagne visual system
- Layered 2.5D hero illustration and floating interface surfaces
- Responsive layout with reduced-motion support
- Student KPIs, subject averages and attendance/achievement scatter plot
- Class filter, student search and support-only filter
- CSV import with required-column validation
- Export of the currently filtered records

The included sample records are fictional. The support indicator is an illustrative demo rule only.
